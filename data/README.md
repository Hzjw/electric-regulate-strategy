# 数据说明

本目录为全国大学生数学建模竞赛官方提供的题目附件，对应一个含光伏、储能与本地负载的并网微网。

## 文件清单

| 文件 | 内容 | 维度 | 说明 |
| :--- | :--- | :--- | :--- |
| `附件1.xlsx` | 典型日：分时电价、小区负载、光伏预测 | 144 段 | 10 分钟粒度，全天 24 小时 |
| `附件2.xlsx` | 全年逐日负载与光伏实际功率 | 365 × 144 × 2 | 仅作为规划依据的事前数据；模型按日滚动使用 |
| `附件3.xlsx` | 每天 4 个时点的光伏预报 | 365 × 4 × 24 | 发布时刻为 0:00 / 6:00 / 12:00 / 18:00，整点粒度 |
| `附件4.xlsx` | 全年实时电价 | 365 × 144 | 问 4 使用 |
| `附件5/` | 结果提交模板 | — | 脚本以此为模板写入，只填数值、保留表头格式 |

## 几个需要注意的口径

1. **时间戳是区间终点**。附件 2/4 的 144 列对应 `(t-1, t]` 的区间，段 `t` 的功率在段末计量。降尺度时要先确认这一点，否则整条曲线会错位一个段。
2. **附件 3 是整点预报，需降尺度到 144 段**。仓库提供 `step`（阶梯保持）与 `linear`（线性插值）两种方式，论文主结果采用 `step`。
3. **光伏有夜间浮点噪声**。夜间应为 0 的列可能出现 −1e−14 量级的负值，装载时统一截零（`np.clip(pv, 0, None)`）。
4. **附件 3 的日期列有合并单元格**，读入后需向下填充（`ffill`），否则同一天的 4 行只有第 1 行带日期。
5. **附件 2/3/4 覆盖 365 天，但报告期是 2025-02-01 ~ 12-31（334 天）**——1 月作为预热期，用于传递 SOC 初值和构造历史样本，不计入费用统计。

## 敏感性参数的取值边界

论文第 6 章做了五维扫描，其中三个临界值值得注意：

| 参数 | 临界值 | 含义 |
| :--- | :--- | :--- |
| 循环成本 `c_cyc` | 0.92 / 1.10 / 1.40 元·kWh⁻¹ | 低于 1.10 时「弃光全部消纳」的策略不变 |
| 紧急购电惩罚倍数 `β` | `β* = 2` | β ≥ 2 时后悔值恒为负（均值计划优于实时优化） |
| 风险厌恶系数 `ρ` | 0.15 | 费用—风险曲线的拐点，在此之内增加保守度几乎不增加成本 |

数据量本身不大（合计约 2 MB），因此直接随仓库分发，无需外部下载。
